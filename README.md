## 🚀 About Me & Learning Journey

Hi there! 👋 I am **Shahrukh Ahmad**, an ambitious **Computer Science student, developer, and continuous learner**. I believe the best way to master technology is by rolling up your sleeves and building real-world, production-ready systems from the ground up.

My technical interests and day-to-day focus revolve around:
- 🌐 **Modern Web Development & Distributed Streaming:** Learning how real-time network streams work, managing in-memory byte buffers with Node.js and Express, and reducing server storage overhead.
- 👁️ **Computer Vision & Deep Learning:** Training custom object detection and instance segmentation models using PyTorch, YOLOv8, and OpenCV.
- 🔒 **Privacy-First Client Engineering:** Building offline-capable Progressive Web Apps (PWAs) using HTML5 Canvas, SVG vectors, and mathematical error-correction (Reed-Solomon algorithms).
- ☁️ **DevOps & Automated Workflows:** Exploring CI/CD automation pipelines using Google Cloud Platform (GCP Cloud Build) and Git.
